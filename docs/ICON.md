# App icon — 1.0

Created using the built-in image generation tool with the user's ICO as a palette reference. The reference itself is not shipped. Full-bleed square art, no transparent corners; iOS applies its own home-screen mask. RGB PNG exports are produced by `scripts/prepare-app-icon.ps1` without altering the artwork.

Final 1024px asset: `CarPlayW/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png`.

## Generation prompt

Use case: logo-brand. Create one finished app icon for CarPlayW, an iPhone app for changing CarPlay car-screen wallpapers. The supplied image is ONLY a color palette/style reference, not an edit target. Use its saturated cyan/electric-blue lower-left, deep violet and magenta middle, warm orange/yellow upper-right palette. 1024x1024 square, full-bleed opaque color across the entire canvas with four perfectly square corners: NO rounded outer icon shape, NO transparent regions, NO surrounding padding, NO arrow or shape extending outside. Refined clean geometric gradient background with a few broad subtle faceted planes, simpler and more polished than reference. Center a bold white, front-facing wide automotive infotainment display outline (landscape ~1.8:1), containing a simple white two-mountain wallpaper silhouette and a round sun with generous clear spacing. Small tasteful integrated white editing-pencil detail at lower right of display to convey wallpaper customization. Symbol occupies about 66-72% of width, readable at iPhone icon sizes. Flat high-end vector-like raster icon, precise edges, balanced optical weights, no text, no letters, no Apple logo, no mockup, no 3D shadows, no extra icons. Produce the icon artwork only.
